# desafio-n8n-delivery
Este Desafio Criativo ensina a planejar automações no n8n estruturando bons prompts para IA. O segredo é combinar intenção clara, contexto e instruções específicas. Através de um processo passo a passo, você organiza ideias em comandos precisos, adicionando elementos gradualmente. Ao final, unirá todas as peças para criar seu prompt ideal!
